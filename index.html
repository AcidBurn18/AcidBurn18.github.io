AI / Vector Retrieval

Homelab Copilot: Self-Hosted Multimodal RAG

Status: Active

Built a 100% self-hosted AI assistant indexing scattered homelab markdown notes, Draw.io XML graph topologies, Excel IP maps, and live Grafana Loki container log streams into a unified hybrid vector search engine.

Problem Searching through 50+ markdown runbooks, spreadsheet IP tables, Draw.io diagrams, and Loki log streams to diagnose container/network failures was slow and fragmented.
Stack Qdrant Vector DB, FastEmbed BM25, MiniLM-L6-v2, Cross-Encoder (ms-marco-MiniLM-L-6-v2), Python, Grafana Loki API, openpyxl, zlib.
Architecture Header-aware markdown chunking, base64 XML graph extraction for Draw.io diagrams, dual-tier adaptive Loki log chunking, Qdrant Reciprocal Rank Fusion (RRF), and cross-encoder logit thresholding (-2.0 cutoff).
Impact Achieved 100% Hit@1 accuracy and 1.0 MRR on a 17-item homelab test suite with sub-700ms retrieval and zero cloud data leakage.

Networking

Six-VLAN Homelab Segmentation

Status: Active

Segmented a flat home network into six purpose-built VLANs with L3 routing and mixed VLAN-aware/unaware hardware.

Problem A flat network mixes management, IoT, security cameras, and servers into one broadcast domain and blast radius.
Stack GWN7721 managed switch, OPNsense (L3 routing, mDNS repeater), VLAN trunking.
Architecture Six isolated VLANs (management, trusted, servers, cameras/NVR, IoT, guest); native VLAN trunking allows non-VLAN APs to deliver untagged traffic cleanly.
Impact Cameras, IoT devices, and core servers sit in strict trust domains with explicit inter-VLAN firewall rules.
